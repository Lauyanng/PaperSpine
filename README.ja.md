## 3 つの使い方

<a id="start-with-skill"></a>

### 初めての方へ · 全工程 Skill

AI 環境のチャットで `$paper-spine` を呼び出し、研究テーマ、データ、初稿のいずれかを渡します。合意した範囲で研究記録、分析、研究図版、編集可能な原稿を作成します。

[**ZIP をダウンロード**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-skill-6.0.0-beta.2.zip) · ![GitHub Release のダウンロード数](https://wubing2023.github.io/PaperSpine/v6/downloads-skill.svg?style=flat)

### 研究者向け · Skills パック

`$paper-spine` で全工程を実行でき、工程ごとに個別の Skill も呼び出せます。たとえば `$paper-spine-followwriting` では、参考論文の論証の組み立て方をもとに、自分の実験結果でセクションを書き直せます。

[**ZIP をダウンロード**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-skills-pack-6.0.0-beta.2.zip) · ![GitHub Release のダウンロード数](https://wubing2023.github.io/PaperSpine/v6/downloads-skills-pack.svg?style=flat)

### 全機能プラグイン · ローカル Web ワークベンチ

ブラウザーで図版を拡大したり、論文をプレビューしたり、改稿のフィードバックを送ったりする場合は、ローカルのワークベンチを追加できます。すべての Skills を収録しており、Windows x64 の Codex で `$paper-spine-web:paper-spine-web` を呼び出して使います。

[**ZIP をダウンロード**](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/paperspine-web-plugin-6.0.0-beta.2-windows-x64.zip) · ![GitHub Release のダウンロード数](https://wubing2023.github.io/PaperSpine/v6/downloads-web-plugin.svg?style=flat)

## インストール、更新、アンインストール

まず、ダウンロードした ZIP の SHA-256 をチェックサム一覧と照合します。展開先のディレクトリで同梱のマネージャーを実行し、元の ZIP のパスと SHA-256 の全桁を指定します。インストール後は、AI 環境で新しいチャットを開きます。

```text
python -B edition_manager.py install "<元の ZIP のパス>" --sha256 <SHA256>
```

マネージャーには Python 3.12 以降が必要です。Web エディションには Windows 版 Python が同梱されており、別途 Codex CLI が必要です。自動更新チェック、手動アップグレード、ロールバック、アンインストールに対応し、論文、データ、ローカルタスクは保持されます。

[インストール、更新、アンインストールの手順](INSTALL-V6.en.md) · [SHA-256 チェックサムファイル](https://github.com/WUBING2023/PaperSpine/releases/download/v6.0.0-beta.2/checksums.sha256) · [V6 リリース](https://github.com/WUBING2023/PaperSpine/releases/tag/v6.0.0-beta.2)

## PaperSpine がエビデンスを論文に反映する方法

- **手元の資料から研究の範囲を決める。** 研究課題だけがある場合は、何のエビデンスが足りず、どの分析が必要かを確認します。結果がすでにある場合は、指定された図版の作成、論証の組み立て、レビューから始められます。後続の工程では、保存した資料と判断を引き継ぎます。
- **書き方の参考と科学的根拠の出典を記録する。** Followwriting は、構成や表現に影響した参考文献の原文を保存します。研究のエビデンスによって論文で主張できる範囲を定め、検証可能な分析、図版の元ファイル、引用文献を原稿に添えます。
- **レビューの結果を同じ原稿に反映する。** 選択した図版とフィードバックを保存します。改稿時は同じタスクでエビデンスを確認し直し、原稿と修正の影響を受ける図版を更新して、変更履歴を残します。

LIGO の事例では、この経路を直接たどれます。論文に記載した到達順序から、2 観測所の時間軸をそろえたひずみデータと 9 通りの前処理結果まで確認できます。[LIGO のエビデンスと元ファイル](https://wubing2023.github.io/PaperSpine/v6/#gravitational-waves)

## 北大西洋の熱帯低気圧の急発達

単体の全工程 Skill を使い、NOAA の熱帯低気圧データ 42 シーズン分を分析しました。比較可能な 6,017 件の 24 時間窓で、閾値を 30 ノットとすると後期は 0.81 パーセントポイント高く、シーズン単位で再標本化した 95% 区間は −1.69 から +3.43 でした。閾値を 25 ノットにすると点推定値は負に転じました。6 パネルの図には、484 件の 24 時間の軌跡、互いに重ならない 3 段階の風速増分、9 つの閾値ごとの点推定値と区間をまとめています。
